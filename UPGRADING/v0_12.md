
# Upgrading from `v0.11.x` to `v0.12.x`

## Important Notes

Version `0.12.x` introduces significant improvements such as zero-copy deserialization which make the new database layout incompatible with the previous version. As a result, the database must be migrated to the new layout. The migration is done automatically on startup and should not require any manual intervention. However, it is highly recommended to **back up your data** before upgrading since it is not possible to downgrade the database once it has been migrated. You may also want to run a mock migration before upgrading to ensure that everything works as expected.

In addition to the database layout changes, multiple settings were renamed:

- `server.http.*` to `http.*`.
- `jmap.folders.*` to `email.folders.*`.
- `jmap.account.purge.frequency` to `account.purge.frequency`.
- `jmap.email.auto-expunge` to `email.auto-expunge`.
- `jmap.protocol.changes.max-history` to `changes.max-history`.
- `storage.encryption.*` to `email.encryption.*`.

## Step-by-Step Upgrade Process

- Stop NordibleMail in **every single node of your cluster**. If you are using the systemd service, you can do this with the following command:

  ```bash
  $ sudo systemctl stop NordibleMail-mail
  ```

- Backup your data following your database system's instructions. For example, if you are using RocksDB or SQLite, you can simply copy the `data` directory to a backup location. If you are using PostgreSQL or MySQL, you can use the `pg_dump` or `mysqldump` commands to create a backup of your database. If your database does not support backups, you can use the [built-in migration utility](https://nordible.co/docs/management/migration) to export your data to a file. For example:

  ```bash
  $ sudo /opt/NordibleMail-mail/bin/NordibleMail-mail --config /opt/NordibleMail-mail/etc/config.toml --export /opt/NordibleMail-mail/export
  $ sudo chown -R NordibleMail-mail:NordibleMail-mail /opt/NordibleMail-mail/export
  ```

- Download the `v0.12.x` binary for your platform (which is now called `NordibleMail` rather than `mail-server`) from the [releases page](https://github.com/NordibleMaillabs/NordibleMail/releases/latest/) and replace the binary in `/opt/NordibleMail-mail/bin`. If you rename the binary from `NordibleMail` to `NordibleMail-mail`, you can keep the same systemd service file, otherwise you will need to update the service file to point to the new binary name. 

- Start the service. In a cluster, you can speed up the migration process by starting all nodes at once. 
  ```bash
  $ sudo systemctl start NordibleMail-mail
  ```

- Upgrade the webadmin by clicking on `Manage` > `Maintenance` > `Update Webadmin`.

## Step-by-Step Upgrade Process (Docker)

- Stop the NordibleMail container in **every single node of your cluster**. If you are using Docker, you can do this with the following command:

  ```bash
  $ docker stop NordibleMail-mail
  ```

- Backup your data following your database system's instructions. For example, if you are using RocksDB or SQLite, you can simply copy the `data` directory to a backup location. If you are using PostgreSQL or MySQL, you can use the `pg_dump` or `mysqldump` commands to create a backup of your database. If your database does not support backups, you can use the `--export` command to export your data to a file. For example:

  ```bash
  $ docker run --rm -v <NordibleMail_DIR>:/opt/NordibleMail-mail -it NordibleMail-mail /usr/local/bin/NordibleMail-mail --config /opt/NordibleMail-mail/etc/config.toml --export /opt/NordibleMail-mail/export
  ```

- The Docker image location has now changed to `NordibleMaillabs/NordibleMail` instead of `NordibleMaillabs/mail-server`. Pull the latest image and configure it to use your existing data directory:

  ```bash
  $ docker run -d -ti -p 443:443 -p 8080:8080 \
             -p 25:25 -p 587:587 -p 465:465 \
             -p 143:143 -p 993:993 -p 4190:4190 \
             -p 110:110 -p 995:995 \
             -v <NordibleMail_DIR>:/opt/NordibleMail \
             --name NordibleMail NordibleMaillabs/NordibleMail:latest
  ```
  
- Since the mount point has changed from `/opt/NordibleMail-mail` to `/opt/NordibleMail`, you will need to update your NordibleMail's configuration file to reflect this change. Open the file `/opt/NordibleMail/etc/config.toml` and update the paths accordingly.

- Upgrade the webadmin by clicking on `Manage` > `Maintenance` > `Update Webadmin`.
